# Kitesurfing support web-app features

Source notes shared with the Kitesurfing Support Bot. The web app implements
these as working surfaces, not a brochure.

## Audience lenses

1. Self-sufficient beginners
2. Kiters new to the area
3. People with limited time
4. People with limited money
5. Different disciplines
6. Focus (transitions, tricks, jumps, lightwind)
7. Kiting alone or with others
8. Skill level
9. Preferences

## Time lenses

10. Length of time available, including travel
11. Time of day available
12. Now / as soon as possible
13. Best opportunities this weekend

## Product features

1. Effective wind speed, taking tide and current into consideration
2. Forecast vs actual, to judge model accuracy
3. Gustiness and direction variability
4. Air pressure, temperature and humidity
5. Wave and chop conditions
6. Safety advice: general, by spot, and by condition
7. Report conditions to a specified group
8. Lost-gear tracking and advice
9. Weather-event prediction (for example SW gales this weekend)
10. Template for entering spot advice
11. Switch perspectives: wind range, future timeslots, spot, profile, popularity
12. In-group-only info
13. BYOK as well as BYOS, plus app / agent / bot access
14. Shared model across rec, kite, fishing, sailing, ski, dive, paddle,
    snorkel, surf, SUP, wing, foil, swim, land-yacht, life-saving, cycle
15. Add your own knowledge
16. Modes: Repairs, R&D, Safety, Virtual, Coach, Manager

## Marketing / distribution

1. Sponsor groups with a special group discount
2. Daily forecast by general location (KAN-style)
3. Prediction reliability scores
4. Accessory / meta layer for other apps (public JSON API)
